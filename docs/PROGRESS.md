### 무엇을 왜 채웠나

**① 별표 (6,747조각) — 팀 원본에 0건이었다**

법 본문은 "시설기준은 별표 8과 같다"에서 끝난다. 실무에 필요한 수치가 전부 별표에 있었다.

- 넣기 전 → "별표 8에 규정되어 있으나 자료에 없습니다"
- 넣은 후 → "제1종보호시설로부터 12m 이상"

법마다 별표 제공 방식이 달라 수집 경로를 셋으로 나눴다.

| 방식 | 해당 법 | 스크립트 |
|---|---|---|
| 본문 PDF 안에 포함 | 고압가스법·수소법·도시가스법 등 | `extract_annex.py` |
| 별표마다 개별 파일 | 액화석유가스법 | `fetch_annex_web.py` → `ingest_annex_pdfs.py` |
| 법령번호로 일괄 수집 | 액법·산업융합촉진법·규제자유특구법 **시행령** | `fetch_annex_by_lsiseq.py` → `ingest_extra_annexes.py` |

시행령·시행규칙 중 별표 누락은 **0건**이다.
「○○법」 본법에는 원래 별표가 거의 없고, 수치는 시행령·시행규칙에 있다.

별표까지 넣었는데도 답변이 막히는 경우가 있었다. 이유는 세 단계였다.

```
법 본문     "시설기준은 별표 8과 같다"          ← 수치 없음

## 2. 챗봇 — 동작 중

### 방식

파인튜닝이 아니라 **RAG**다. AI가 법을 아는 게 아니라, 매번 관련 조문을 찾아 넣어 준다.

```
질문 → ① 32,217조각에서 검색(글자 BM25 + 뜻 벡터, 내 서버, 0.1초)
     → ② 찾은 조각만 읽고 답변(제미나이 무료 API)
     → 답변 + 근거 원문 + 이어질 질문 3개
```

자료에 없으면 "없다"고 답한다. 지어내지 않는다.

### 잘못된 답을 막는 장치

1. **근거 강제** — 제시된 조각 안에서만 답하도록 지시
2. **수치 대조** — 답변의 숫자·조문번호가 근거에 실제로 있는지 기계 검사
3. **자료 없음 감지** — 검색 점수가 낮으면 비슷한 조문으로 때우지 않음
4. **원문 병기** — 근거 전문을 화면에 함께 표시

### 정확도 측정

정답셋 20문항으로 채점했다(`eval_set.json` · `eval_run.py` · 결과 `정확도측정.md`).

| | 결과 |
|---|---|
| 내용 정답 | **19 / 20** |
| 근거 일치 | **20 / 20** |

틀린 1문항("제조허가는 누구에게 신청해?")도 답 자체는 맞았다.
"허가관청(시장·군수·구청장)"이라고 답했는데, 근거로 법 제4조 대신
시행령 제3조를 들었다. 채점은 핵심 조문을 요구해서 X로 처리했다.

자료에 없는 것을 묻는 문항(부지 임대료 상한)에는 지어내지 않고
"자료에 없다"고 답했다.

```

  9개를 줄세워 뒀다. 한 모델이 하루치를 다 써도 서비스는 계속 뜬다.

## 4. 해외 법령

### 미국 (캘리포니아) — 정리 완료

멘토님 지침은 "체계가 설명 가능할 때까지". 전문 수집은 하지 않는다.

`문서/미국_캘리포니아_인허가.html` 에 공부용으로 정리했다.

핵심 세 가지:

1. **연방법에 수치가 없다** — 안전·건축 규제 권한이 주에 있다.
   연방은 운송(DOT)·근로자 안전(OSHA)·배출(EPA)만.
2. **NFPA 2는 민간 표준인데 채택되면 법이 된다** — KGS Code와 같은 자리,
   다른 출신. 그래서 "어느 도시가 몇 년판을 채택했는지"까지 봐야 한다.
3. **CEQA는 허가가 재량적일 때 걸린다** — 한국 환경영향평가법은 사업 규모로
   대상이 정해지는데, 캘리포니아는 허가의 성격으로 갈린다.

최근 흐름으로 SB 1291(2022) · SB 1418(2024)이 인허가를 단축했다.
특히 SB 1418은 허가를 비재량으로 바꿔 **CEQA를 함께 빼는** 방식이라 이야깃거리가 된다.

미확정으로 남긴 것: 대기 배출허가가 통상 걸리는지 (Air District마다 다름).

### 일본 — 정리 완료

`문서/일본_수소_인허가.html` 에 미국편과 같은 범위(체계 설명 수준)로 정리했다.
뼈대는 한국과 같고(고압가스보안법 → 一般則 → 例示基準), 例示基準이 KGS Code 자리다.
2024년 개정으로 달라진 점과 3국 비교표를 넣었다. 수치 인용원은 대조가 더 필요하다.
